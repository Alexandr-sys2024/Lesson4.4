# Lesson4.4 - Бой с монстром

## 📌 Описание
Этот проект — консольная игра, в которой игрок сражается с монстром, выбирая разное оружие.
Игрок может использовать **меч, лук или топор**, чтобы наносить урон монстру. Победа наступает, когда здоровье монстра падает до 0.

## 🚀 Установка и запуск

### 1. Убедитесь, что у вас установлен Python
Проверьте версию Python:
```sh
python --version
```
Проект протестирован на **Python 3.8+**.

### 2. Клонируйте репозиторий
```sh
git clone https://github.com/Alexandr-sys2024/Lesson4.4.git
cd Lesson4.4
```

### 3. Запуск игры
```sh
python main.py
```
Выберите оружие и атакуйте монстра!

## 📂 Основные файлы
- **`main.py`** – содержит весь код игры.
- **`.gitignore`** – стандартный список игнорируемых файлов.
- **`LICENSE`** – лицензия MIT.

## 🎮 Геймплей
1. Игрок начинает бой с базовым оружием – мечом.
2. В каждом раунде можно **сменить оружие** перед атакой.
3. Монстр получает **10 урона за удар**.
4. Когда здоровье монстра падает до **0**, игрок **побеждает**!

## 🔥 Возможности
✅ Различные виды оружия: меч, лук, топор.
✅ Выбор оружия перед атакой.
✅ Простая механика для начинающих программистов.
